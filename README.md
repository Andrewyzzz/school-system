# 学校教师任务与薪资管理 Demo

这是一个本地静态网页 Demo，用于演示学校任课老师课时签到、签到记录、薪资试算和财务结算流程。

## 演示账号

- 老师账号：李明，只能查看自己的课时任务、签到入口、签到记录、月度确认和薪资明细。
- 财务账号：张会计，可以查看不同老师的签到记录，并进行薪资结算。

## 本地运行

```bash
python3 -m http.server 4173
```

然后打开：

```text
http://localhost:4173/
```

## 当前功能

- 多账号角色切换
- 老师本人课时任务
- 老师签到入口和扫码演示
- 老师本人签到记录
- 月度工作量确认
- 薪资自动试算
- 财务查看不同老师记录
- 财务薪资结算锁定
- 异常记录提醒

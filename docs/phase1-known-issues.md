# 第一阶段已知问题清单

## 需要现场验证

- 手机摄像头扫码兼容性需要在学校实际手机、浏览器和网络环境中验证。
- 正式网页扫码必须使用 HTTPS；本地 `localhost` 可用于开发验证。
- 微信小程序版本应改用微信原生扫码能力，复用当前后端考勤接口。

## 当前试运行限制

- 排课高级能力仍放在后续迭代，包括老师不可用时间、偏好、连堂课、专用教室、合班/走班/分层教学、拖拽调整、多版本回滚和调课审批。
- 第一阶段薪资规则聚焦任课老师：固定工资、岗位工资、正常课时、早自习、晚自习、周末课、补课和个税试算。
- 财务锁定工资前，系统会阻止仍存在待处理或异常课时的老师进入锁定。
- 当前使用本地 JSON 文件作为试运行数据存储，正式上线前需要切换到数据库迁移方案。

## 运营注意事项

- 老师默认密码上线前必须要求修改，管理员可重置密码或停用账号。
- 教室大屏密钥应由总校或信息管理员统一管理，不能贴在公开文档里。
- 薪资规则调整后，已锁定工资不应被重新生成；未锁定数据可重新生成。

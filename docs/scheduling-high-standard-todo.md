# 排课系统最高标准 TODO

更新时间：2026-06-19

目标：把当前排课模块从“可生成无冲突课表”升级为“接近成熟商业排课软件”的排课引擎，覆盖复杂规则配置、工业级求解、失败诊断、人工调整、版本发布、质量评分和规模化验收。

## 0. 最高标准定义

成熟排课系统不能只看是否生成课表，而要同时满足：

- 硬约束 100% 满足：老师、班级、教室、时间、禁排、专用教室、锁定课节、课程每日上限等不能冲突。
- 软约束可评分：老师课量均衡、上午/下午分布、连续课节、主科时段、体育/实验偏好等要可量化。
- 失败可解释：排不出来时，系统必须告诉管理员是哪门课、哪个老师池、哪个禁排规则或哪个资源导致问题。
- 可人工接管：拖拽、换老师、换教室、锁定课节、局部重排、冲突即时提示都要有。
- 可发布回滚：草稿、正式版、历史版、差异对比、回滚和发布审计必须完整。
- 可规模化验收：至少覆盖 1000 名教师、多学部、多年级、多约束的测试集。

## 1. P0：约束模型与配置能力

- [ ] 统一排课规则数据模型：学部、年级、班级、课程、老师、教室、时段、学期、周次、规则版本。
- [ ] 明确硬约束和软约束分类，所有规则在数据库中带 `constraintType=hard|soft`。
- [ ] 课程规则支持：周课时、单节时长、是否允许连堂、每日上限、偏好时段、禁排时段。
- [ ] 老师规则支持：不可用时段、最大日课量、最大连续课量、偏好时段、偏好集中/分散。
- [ ] 教室规则支持：普通教室、实验室、机房、操场、美术室等专用教室类型。
- [ ] 班级规则支持：每日课量上限、上午/下午课量分布、主科分布、班级禁排。
- [ ] 课程-教室绑定：物理实验必须实验室、体育必须操场、信息课必须机房等。
- [ ] 合班课模型：多个班共享同一节课、同一老师、同一教室。
- [ ] 走班/分层教学模型：一个班拆成多个教学组，每组可绑定不同老师和教室。
- [ ] 锁定课节模型：锁定后自动重排不得移动。
- [ ] 外部占用模型：其他年级已发布课表、老师外出、教室活动占用进入全局时间线。

验收标准：

- [ ] 任意一条规则可在 UI 配置、保存、读取、参与排课。
- [ ] 硬约束冲突必须阻止发布。
- [ ] 软约束不阻止发布，但必须进入评分和诊断报告。

## 2. P0：排课前预检

- [ ] 生成前检查课程总课时是否超过班级可用时段。
- [ ] 检查每门课老师池是否为空。
- [ ] 检查老师可用时段是否足够覆盖被分配课程。
- [ ] 检查专用教室容量是否足够。
- [ ] 检查禁排规则是否导致某课程无候选时段。
- [ ] 检查锁定课节是否已经违反当前规则。
- [ ] 输出预检报告：通过、警告、阻塞三类结果。
- [ ] 阻塞项给出修复建议，例如“增加物理老师池”“放宽周三上午禁排”“增加实验室可用时段”。

验收标准：

- [ ] 明显无解的配置在求解前被拦截。
- [ ] 管理员能看懂为什么无解，以及应修改哪个配置。

## 3. P0：工业级求解器升级

- [ ] 将当前 CP-SAT 默认求解时间从 `10s` 升级为可配置，建议试运行 `30s / 60s / 120s` 三档。
- [ ] 将候选上限从固定截断改为覆盖式候选生成，避免只保留成本最低的前 N 个导致误删可行解。
- [ ] 候选生成必须覆盖不同日期、上午/下午、不同老师和不同教室。
- [ ] 增加两阶段 CP-SAT：
  - [ ] 第一阶段只求硬约束可行解。
  - [ ] 第二阶段在可行解基础上优化软约束评分。
- [ ] 支持未排课惩罚变量：极端情况下允许返回“部分未排 + 原因”，而不是直接失败。
- [ ] 使用 fallback 结果作为 CP-SAT warm start，帮助 CP-SAT 从可行课表开始优化。
- [ ] 保留高级启发式算法 fallback，但定位为兜底和 warm start 来源。
- [ ] 输出 CP-SAT 状态：`OPTIMAL`、`FEASIBLE`、`INFEASIBLE`、`UNKNOWN`、耗时、冲突数、分支数、目标值、best bound。
- [ ] 当 CP-SAT 失败时，返回候选不足任务、冲突资源、最紧张老师/教室、被触发最多的约束。

验收标准：

- [ ] 常规规模下 CP-SAT 命中率达到 95% 以上。
- [ ] fallback 被触发时，页面必须显示原因和建议。
- [ ] 任何情况下不得静默发布有硬冲突的课表。

## 4. P0：排课质量评分

- [ ] 建立 100 分评分模型。
- [ ] 硬约束：只要违反即不可发布，不进入扣分发布。
- [ ] 软约束评分项：
  - [ ] 老师周课量均衡。
  - [ ] 老师日课量均衡。
  - [ ] 老师连续上课控制。
  - [ ] 老师碎片化程度。
  - [ ] 班级每日课量均衡。
  - [ ] 主科上午分布。
  - [ ] 体育/艺术/实验偏好时段。
  - [ ] 同一班同一科不要过度集中。
  - [ ] 专用教室利用率。
- [ ] 每条扣分都能点开看到对应课节。
- [ ] 支持对比两版课表评分差异。

验收标准：

- [ ] 排课结果显示“硬冲突 0、评分 X/100、未满足偏好 N 条”。
- [ ] 管理员能知道分数为什么低。

### BUG-20260618-002 当前运行库 readiness 失败：未发布课表

| 字段 | 内容 |
| --- | --- |
| 严重级别 | P0 |
| 模块 | 数据初始化 / 行政排课 / readiness |
| 现象 | `/api/phase1/readiness` 返回 `passed=false`，失败项为 `schedule_conflict` 和 `teacher_schedule` |

| 建议 | 增加“生成试运行排课数据”脚本，或在部署后由行政账号完成配置、生成、发布，再运行 readiness |

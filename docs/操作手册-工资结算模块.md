# 工资结算模块操作手册

对应验收清单 9.3。适用岗位：财务（总校、小学部、初中部、高中部）、系统管理员、任课教师。

> 本手册按系统的实际界面编写，菜单名与按钮名与屏幕上完全一致。
> 界面改动后请同步修改本手册——`npm run test:manuals` 会检查手册里提到的
> 菜单与按钮是否还存在。

---

## 一、计薪口径

**排给教师的课就算这位教师的课时费**，不需要签到，也不看是否已经上过。
三条推论：

| 情形 | 谁拿这节课的钱 |
| --- | --- |
| 正常排课 | 课表上写的那位教师 |
| 代课（调课审批通过） | **代课教师**——审批时课次已经改派到他名下 |
| 请假且安排了代课 | 代课教师 |
| 请假但没安排代课（课次取消） | **谁也不拿**，这节课不计薪 |

所以「加上代课、减掉请假」不需要任何额外操作：审批一通过，课表就变了，
工资跟着课表走。

一个月还没上完时不能锁定工资——未上的课已经计薪了，锁死之后如果请假取消，
改不了。系统会拦下来。

---

## 二、每月结算的顺序

```
课时数据（老师签到，教务确认）
    ↓
维护本学期工资档案（职级/考核档/住房档）  ← 学期初做一次
    ↓
维护本月特殊奖扣                          ← 只记例外项
    ↓
保存单个老师工资草稿
    ↓
发布本月工资明细       ← 老师这时才看得到
    ↓
老师确认 / 提出异议
    ↓
处理异议
    ↓
批量锁定可发工资       ← 锁定后不可改，走审批才能解锁
    ↓
三方对账               ← 对不平不要发钱
```

**发布之前老师看不到任何金额**，可以放心反复试算。

### 学部隔离

小学部财务只能看到和结算小学部的老师，初中、高中同理。总校财务看全校。
这是按账号绑定的财务范围自动生效的，不需要每次筛选。

## 三、学期初：维护工资档案（菜单：薪资结算）

### 2.1 全校薪资规则（菜单：薪资配置）

先在 `薪资配置` 里维护全校统一的规则：不同岗位、职级、考核档、校龄、住房、
岗位津贴各对应多少钱。改完点 `保存规则`。

这里配的是"标准"，不针对具体某个老师。

### 2.2 老师个人档案

回到 `薪资结算`，在"本学期工资档案"一段维护单个老师的职级、考核档、住房档、
岗位角色。默认只读，要改先点 `编辑档案`，改完保存；不改点 `取消`。

**职称以人事档案为准**。人事把某位老师从三级教师改成高级教师，
这里的职称和对应的基本工资档会自动跟着变——不要也不能在工资侧改职称。

档案是"本学期稳定生效"的，一个学期定一次，不要按月改。

## 四、每月结算（菜单：薪资结算）

### 3.1 选月份和老师

顶部选核算月份。用搜索框按姓名或工号找老师，点 `查询`。

### 3.2 本月特殊奖扣

"本月特殊奖扣"一段只记**例外项**：临时补发、特殊奖励、考勤扣减。
点 `添加奖扣项` 加一条，填金额和说明，点 `保存本月奖扣`。

常规工资、课时费、岗位津贴由上面的学期档案和全校规则自动算，
**不要在这里重复录入**——录了会算两遍。

### 3.3 核对并保存草稿

"工资明细"一段显示这位老师本月的完整工资构成：基本工资、岗位工资、考核工资、
校龄工资、住房补贴、课时费、补发、扣减、应发合计。

每一项都标了口径（例如"高级教师 · 小学正课 40 分钟/节"），核对无误点
`保存该老师工资`。这一步存的是财务草稿，老师还看不到。

**排给教师的课都计入课时费**，代课的课算在代课教师名下，请假期间未安排代课的课次不计薪。

### 3.4 发布

所有老师草稿都保存好之后，点 `发布本月工资明细`。发布后老师在
`工资确认` 菜单里能看到自己的工资单。

### 3.5 处理异议

老师提出异议后，对应记录会标出来。财务核实：

- 确实算错了 → 改正后重新保存
- 没有算错 → 点 `异议已处理/确认无误`

无论哪种，处理结果都会同步给老师。

### 3.6 锁定

全部确认完毕后点 `批量锁定可发工资`，或对单个老师点 `锁定该老师工资`。

**锁定后当月薪资账套不可再写入**。改不了金额，也不能重新生成——
这正是验收要求的"审批完成后尝试修改，确认被拒"。

确实需要改动时点 `解锁重算`，系统会走多级审批（人事复核 → 财务复核 →
校领导审批），解锁次数会被记录。频繁解锁说明核算流程有问题。

### 3.7 导出

点 `导出工资明细` 下载当月明细。银行卡号只显示后四位，
工资条包含签字栏，可以直接打印发放。

## 五、财务首页（菜单：财务首页）

### 4.1 薪酬预算

显示本学期薪酬预算的执行情况。预算由学期初的"薪酬总额预算确认"审批确定，
**这里仅作展示，不限制发放**——预算超了不会拦住工资，但会显示出来。

### 4.2 分组汇总

按 `按学部`、`按学科`、`按年级` 三个维度看工资总额、待处理课时和异常，
不需要逐个老师翻。

发工资之前先看这里：某个学科的总额比上月高出很多，多半是课时数据有问题。

---

## 六、历史工资记录（菜单：工资记录）

按学期和月份查看已发工资汇总，点 `查询` 筛选，点 `导出明细 CSV` 下载。

往年的月度工资账套即使已归档，在这里仍然查得到、导得出。

---

## 七、账套与对账（菜单：账套管理）

### 6.1 每月新建薪资账套

在"新建账套"一段选"薪资财务账套（按月）"，期间填 `2026-09` 这样的月份，
点 `建立账套`。勾选结转会自动带入现有教职工名册。

**建立新账套不会清除往年数据**。往年工资、历史课表都还在，随时可查。

### 6.2 三方对账

**发工资之前必须跑一次**。在"三方对账"一段选核算月份，点 `运行对账`。

系统核对三件事是否一致：

| 口径 | 来源 |
| --- | --- |
| 人事在岗人数 | 人事档案 |
| 本月工资单数 | 薪资模块 |
| 排课总课时 vs 计薪课时 | 排课模块 vs 薪资模块 |

差异会落到**具体的人**（工号 + 姓名 + 原因），不是只报一个总数。常见差异：

| 差异类型 | 含义 | 怎么办 |
| --- | --- | --- |
| 在岗但无工资单 | 新入职漏建 | 补建工资明细 |
| 已离职，仍生成了工资单 | 离职流程没跟上 | 核实后作废该工资单 |
| 人事档案中无在岗记录 | 数据问题 | 联系人事核对档案 |
| 课时对不上 | 排课与计薪的课时数不一致 | 查考勤和调课记录 |

**对不平不要发钱**。点 `查看上次结果` 可以调出上一次的对账结果。

差异很多时列表只显示前 200 条，页面上会写明总共多少处。

### 6.3 锁定与归档

每月工资审批完成后，对应的薪资账套自动锁定。也可以在账套列表里手动点
`锁定`——需要填写原因，这条会进操作日志。

`归档` 会把该期间的数据从内存卸出，加快系统启动，但仍可查询和导出。
归档是终态，不可逆。

### 6.4 单账套备份与恢复

在账套列表里点 `导出备份` 下载单个账套的 JSON 备份文件，
可以交给档案室离线保存。

恢复：在"导入恢复"一段选择备份文件，点 `导入恢复`。
默认拒绝覆盖已有数据，确需覆盖要先勾选"允许覆盖已有账套"——
**覆盖不可撤销**。恢复功能仅限系统管理员。

## 八、统计报表（菜单：统计报表）

- **周教学工作量台账**——每位老师每周的课时分布，用来核对课时费
- **年度薪资汇总**——按人按年的工资合计，已结算与在途分开列

点 `刷新` 更新，`导出 Excel` 下载，`打印 / 导出 PDF` 直接打印。

导出的 Excel 里金额和课时是**数字格式**，可以直接求和与做透视表。

---

## 九、老师端：工资确认（菜单：工资确认）

财务发布后，老师在这里核对本月工资。

页面显示工资明细和计薪工作量。核对无误点 `确认工资明细`；
有问题点 `提出异议`，填写具体哪一项有疑问。

**排给你的课都计薪**——课时比预期少，多半是有课被请假取消了，在 `我的课时` 里能看到哪几节。

## 十、常见问题

**某位老师的课时费明显偏少？**
按顺序查：① 有没有课被请假取消（`我的课时` 里标「已取消」的）；② 课表有没有被调课或改派代课；
③ 学期工资档案里的职级和考核档对不对。三方对账能一次性把这类问题列出来。

**改了老师的职称，工资没变？**
职称必须在**人事档案**里改，改完工资侧立刻生效。在工资侧改是改不动的——
职称以人事为准。

**锁定之后发现算错了怎么办？**
点 `解锁重算` 走审批。解锁会被记次数，不要当成常规操作。
正确做法是锁定之前把对账跑通。

**对账报出一千多处"在岗但无工资单"？**
说明这个月还没生成工资明细。先完成结算再对账。

**能看到别的学部的老师吗？**
不能，除非用总校财务账号。这是按账号的财务范围限定的。

**往年的工资还查得到吗？**
查得到。归档只是不占内存，`工资记录` 里按月份查询和导出都正常。

**导出的工资条能直接发吗？**
能。银行卡号只显示后四位，带签字栏，可以直接打印。
但导出文件含全员工资，请按机密资料管理。

---

## 十一、注意事项

1. **发钱之前跑对账**。这是最后一道拦网，差异会落到具体的人。
2. **奖扣只记例外**。常规项自动算，重复录入会算两遍。
3. **职称在人事侧改**，工资侧跟着走。
4. **锁定不是走过场**。锁了要三级审批才能解，锁之前请核对清楚。
5. **导出的工资明细按机密管理**。里面是全员的工资金额。
6. **不要绕过系统改数据库**。改库不会留审计，也不会触发对账。

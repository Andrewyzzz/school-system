# 第一阶段试运行操作手册

## 目标

第一阶段试运行用于验证任课老师排课、扫码签入签出、月度工作量确认、薪资明细生成、财务复核锁定和工资明细导出。

## 账号

- 行政账号：`admin / 123456`
- 财务账号：`finance / 123456`
- 老师账号：`teacher0001 / 123456` 至 `teacher1000 / 123456`
- 演示老师账号：`teacher / 123456`

## 行政排课

1. 使用行政账号登录。
2. 进入“行政排课”。
3. 选择学部和年级。
4. 在“科目与老师配置”中确认每门课的任课老师 ID，必要时修改并保存。
5. 点击“一键生成排课”。
6. 确认冲突校验为 0。
7. 如需调整，选择课节后修改老师、日期、节次或教室。
8. 可锁定已确认课节，再点击“重排未锁定课程”。
9. 点击“确认并发布到老师端”。

## 教室动态二维码

1. 教室电脑打开 `classroom.html?roomId=教室ID&displayKey=教室大屏密钥`。
2. 页面会持续向后端获取短时有效二维码。
3. 老师手机打开系统网页，进入“签入/签出入口”。
4. 启动摄像头扫码；如浏览器权限失败，可粘贴二维码内容到“手动输入兜底”。

## 老师流程

1. 老师登录后查看“工作台”和“我的课表”。
2. 上课前在允许窗口内扫码签入。
3. 下课后在允许窗口内扫码签出。
4. 进入“考勤记录”查看通过和拦截流水。
5. 月末进入“月度确认”，确认本人工作量。
6. 进入“薪资明细”，查看本人应发、扣税和实发项目。

## 财务流程

1. 财务登录后进入“财务首页”。
2. 分页搜索老师，查看工作内容、考勤记录和异常。
3. 进入“薪资结算”，选择老师。
4. 按需调整薪资规则并保存。
5. 点击“批量生成本月薪资”或进入单个老师详情自动生成薪资明细。
6. 对单个老师点击“财务复核通过”。
7. 确认无待处理和异常课时后点击“锁定该老师工资”。
8. 点击“导出工资明细”下载 CSV。

## 验收接口

财务或行政登录后可调用：

```text
GET /api/phase1/readiness
```

接口会返回账号数量、权限、分页性能、排课发布、扫码考勤、异常不计薪和薪资锁定等自动检查结果。

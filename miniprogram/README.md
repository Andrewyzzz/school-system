# 富源学校教师端小程序 MVP

这是第一阶段老师端微信小程序 MVP，复用当前线上后端：

```text
https://fuyuanschool.org
```

## 已包含功能

- 老师账号登录
- 老师工作台
- 我的自然周课表
- 真实扫码签入/签出：`wx.scanCode()`
- 演示提交签入/签出：自动获取教室动态二维码并使用课表允许时间提交
- 我的考勤记录
- 我的总薪资
- 月度工作量确认
- 通知中心

## 微信开发者工具导入

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本仓库的 `miniprogram` 目录。
4. AppID：
   - 没有正式小程序 AppID 时，可先使用测试号/游客模式；
   - 正式联调时改成学校自己的小程序 AppID。
5. 编译运行。

## 微信后台需要配置

正式 AppID 下，需要在微信公众平台小程序后台配置：

```text
开发管理 -> 开发设置 -> 服务器域名 -> request 合法域名
https://fuyuanschool.org
```

扫码使用微信原生 `wx.scanCode()`，不需要浏览器摄像头权限，但小程序必须是真机或开发者工具支持扫码模拟。

## 测试扫码

真实扫码流程：

1. 小程序登录老师账号。
2. 进入“扫码签到”。
3. 选择一节本人课时。
4. 在电脑浏览器打开页面里显示的“教室电脑大屏地址”。
5. 点击“真实扫码”，用手机扫电脑上的动态二维码。

如果当前真实时间不在该课时签入/签出窗口内，后端会按防作弊规则拦截。

演示提交流程：

1. 进入“扫码签到”。
2. 选择一节本人课时。
3. 点击“演示提交”。
4. 小程序会自动获取同教室动态码，并使用该课时允许的签入/签出时间提交。

正式上线前，应隐藏“演示提交”按钮，只保留真实扫码。
